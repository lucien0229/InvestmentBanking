# Allow purpose-scoped Account template quarantine uploads

V1 permits a separately supplied Account Reusable Template to enter through an Account-scoped Upload Session whose authorization is bound to the exact Actor, `account_reusable_template` purpose, batch, immutable quarantine path, limits, and expiry without inventing a Deal. Deal Material uploads remain bound to one Deal, and no live Deal object may be promoted into the Account template path. Every Account- or Deal-scoped upload still enters the same fail-closed safety quarantine before preview or substantive processing; an Account Template must additionally pass its applicable compatibility controls before it can be used. The browser writes only the exact quarantine path through Supabase TUS using a fresh Clerk Bearer token and Storage RLS; it cannot list, overwrite, upsert, change purpose, or use another object-store path. This supersedes ADR 0014 only where its wording required every Upload Session to be Deal-bound, while preserving its mandatory-quarantine decision and ADR 0019's separate-clean-template boundary.
