# Sign canonical Artifact Manifests

V1 binds every source, Native Artifact, Reader Copy, control record, and archive member with SHA-256 and signs the UTF-8 RFC 8785 JSON Canonicalization Scheme representation of its Artifact Manifest using an environment-specific Ed25519 key. The signature envelope records the signing key ID, production and test keys are separate deployment secrets, public verification keys are published through a stable well-known registry and retained for historical validation, and key rotation never rewrites prior artifacts; V1 does not add OOXML package signatures, PDF digital signatures, or a public-certificate trust chain. This fixes a portable offline integrity contract while keeping deployment origin, byte integrity, Banker approval, Professional Usability, and External-Use authorization as separate claims.
