# Prototype the Self-Serve Deal Workspace First-Value Journey

Type: prototype
Status: resolved
Blocked by: 05, 07, 08

## Question

What product form and interaction sequence let an Individual Banker discover, purchase, create a Deal, supply the minimum inputs, supervise AI work, inspect evidence, correct results, and obtain the premium hero outcome without offline onboarding?

Use `/prototype` to create a low-cost, disposable interaction artifact at the minimum fidelity needed for live user reaction. Test the complete first-value journey rather than visual styling: entry point, product form, Deal creation, source intake, progress and failure states, evidence inspection, human correction, deliverable preview, export, and return/repeat loop. Resolve through live feedback. Do not enter high-fidelity visual design or production implementation.

## Answer

The user validated an asymmetric synthesis: **C owns outcome-first discovery, A owns guided first correct use inside the product, and B is the durable Deal Workspace shell**. C remains inside B as the Execution Package / Readiness view; these are lifecycle modes around one authoritative Deal Workspace, not three permanent peer products.

The first unmistakable value moment is the controlled closure of the synthetic `$18.4m` / `$17.8m` EBITDA conflict and `$6.2m` / `$4.7m` Cash extraction error: exact lineage is visible, the original extraction and both source values remain in history, the Banker records typed scope-bound decisions, the `$1.5m` deterministic tie-out recovers, and the affected workbook, CIM, reader copy, QC, readiness, and authorization consequences are shown. The first Deal then graduates into B for persistent work, package control, export, and new-event Revision loops.
