# Retain a minimal claimant for deletion status

V1 removes normal Account or Deal access immediately when a Deletion Request is accepted but retains a separate, minimal Deletion Status Claimant binding the exact request to the authentication provider issuer and subject; the same provider identity remains authentication-only and has no product relationship beyond proving this claimant. The claimant may issue only short-lived, read-only Deletion Status Grants, contains no Deal content, display name, unnecessary email copy, or ordinary Account authority, and is removed 30 days after terminal deletion completion or after any preservation exception resolves, after which the final provider identity is deleted when no other lawful product relationship exists. This deliberately retains the smallest identity link needed to prove deletion progress instead of choosing either an unsafe long-lived bearer credential or immediate identity erasure that would make the promised status and completion evidence inaccessible.
