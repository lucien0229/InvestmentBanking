# Separate Web delivery from the versioned API runtime

V1 implements the authenticated Web experience in a Next.js TypeScript application and the versioned `/api/v1`, Webhook, SSE, authorization, command, query, and transactional control plane in a separate Fastify TypeScript application within the same monorepo and modular product control plane. Browser-facing rendering and navigation therefore do not own durable domain transactions or long-lived Job contracts, while both applications share versioned domain and contract packages and deploy together on the single United States VPS. This accepts two TypeScript processes and an explicit internal boundary to keep UI release behavior, API compatibility, streaming connections, and authoritative business invariants independently testable without creating product microservices.
