# Keep Artifact and Audit signing keys in Google Cloud KMS

V1 stores the Artifact Manifest and Audit Checkpoint Ed25519 private keys as two independent Google Cloud KMS `EC_SIGN_ED25519` asymmetric-signing keys at the software protection level rather than exporting private key files to the VPS. Separate Signer identities receive only the exact signing permission for their purpose, signatures bind the KMS key version, public keys remain available for historical verification, and rotation creates a new version without rewriting earlier artifacts or checkpoints. This accepts KMS availability and provider dependence to remove private signing-key custody, copying, backup, and rotation from the application host while preserving the already selected Ed25519 verification contract.
