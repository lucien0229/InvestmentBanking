# Suspend Recipient Access during reversible restrictions

V1 preserves an otherwise-valid Recipient Access as suspended, rather than revoking or silently preserving it, while an open Payment Dispute or Account Security Restriction is active. Suspension immediately denies prospective reads and invalidates Recipient Sessions and stream grants; after every cause clears, the Individual Banker must explicitly resume the unchanged exact Access with a Sensitive Action Grant, while expiry, invalidation, permanent loss of an accountable Actor, deletion, Post-Term entry, and a lost dispute still revoke or terminate access. This keeps authorization and prior-use history truthful without allowing a reversible commercial or security restriction to reopen external access automatically.
