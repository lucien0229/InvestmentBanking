# Persist narrative Deliverable content as schema-governed payloads

V1 persists each narrative Deliverable Revision's immutable semantic content as a strict, closed, schema-validated JSONB payload bound to an exact Deliverable type, content-contract version and digest, while typed PostgreSQL relations remain authoritative for Facts, Claims, Evidence Relationships, Analyses, Recommendations, Quantitative Measures, Human Decisions, permissions, lifecycle state, version relationships, and Lineage. Workbook semantics remain authoritative in relational Model, Calculation, Scenario, Buyer, Bid, and Process records, with layout and build mappings treated as versioned generation contracts rather than financial truth. Native Artifacts, Reader Copies, and accepted reimports remain immutable Protected Deal Objects and cannot replace semantic authority. This accepts schema compilation, validation, and migration work to avoid either forcing heterogeneous document trees into brittle universal tables or allowing an unconstrained JSON document to bypass database-enforced financial and control invariants.
