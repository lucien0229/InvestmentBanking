# Use Supabase Pro for production data services

Before the first Banker Pilot that may receive Confidential Deal Material, V1 uses United States-region Supabase Pro PostgreSQL as the transactional System of Record and Supabase Storage as the authoritative Deal Material object store; [ADR 0041](0041-use-supabase-auth-for-v1-authentication.md) separately governs Supabase Auth. Object revisions use unique content-addressed keys and are never overwritten or upserted, application tombstones separate logical deletion from controlled physical removal, and the VPS NVMe retains only bounded working data and encrypted recovery copies subject to checksum and restore drills. Local-only PostgreSQL and file storage remain permissible for development and synthetic proof, but cannot cross the Confidential Deal Material launch gate because a single host cannot supply the required independent recovery boundary and Supabase database backups do not themselves preserve Storage object contents.
