# 34 — Restore Project Northstar through the production-shaped topology

**What to build:** Complete the one-US-VPS production topology and prove recovery by restoring Project Northstar through the real Web/API/Gateway/dispatcher/worker boundaries. Include content-blind observability, encrypted transactional/object recovery copies, signed manifests/checkpoints, retention/deletion awareness, and the confirmed absence of interactive operator recovery.

**Blocked by:** 05 — Create an exact Deal and complete Paid Preflight; 06 — Accept one protected Deal file as an immutable Source Record; 12 — Generate the Analysis and Valuation Workbook as a circulation candidate; 30 — Produce a complete index-first Archive Package; 31 — Delete Account and Deal data through a verifiable lifecycle.

**Status:** ready-for-agent

- [ ] The production-shaped release runs behind the fixed ingress with separate Web, API, Gateway, dispatcher, worker/coordinator/executor, rootless sandbox, signer, retention, backup, and measurement runtime identities.
- [ ] Encrypted logical database backups, protected-object recovery copies, completeness/digest manifests, and restore verification meet the declared RPO/RTO evidence contract.
- [ ] Restore reconstructs Project Northstar transactional state, protected exact bytes, current/historical Revisions, Decisions, manifests, Audit checkpoints, retention/deletion identities, and RLS before restored data becomes accessible.
- [ ] Deletion Tombstones and expired measurement links prevent restore from reintroducing deleted authority or identity relationships.
- [ ] OpenTelemetry/Sentry and runbooks expose only allowlisted privacy-safe health, release, queue, reason, Job, backup, and recovery identities and reject seeded content canaries.
- [ ] V1 contains no human Deployment Operator product session or interactive recovery command; automated recovery uses purpose-scoped Runtime Principals and Banker-controlled recovery remains inside product flows, per ADR 0036 and INT-DEF-004.
- [ ] Cross-tenant denial, KMS/signature corruption, sandbox escape/egress, backup omission, stale restore, deleted-data resurrection, and minimum-VPS deadline tests block release as applicable.
- [ ] The successful restored Web/HTTP/file view and negative operator probes satisfy AC-068 and AC-070 through AC-072.
