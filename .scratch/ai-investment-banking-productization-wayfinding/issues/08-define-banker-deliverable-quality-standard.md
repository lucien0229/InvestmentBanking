# Define the Banker Deliverable and Quality Standard

Type: research
Status: resolved
Blocked by: 01, 04, 06

## Question

Which editable native files and reader-facing outputs must the selected first workflow produce, and what source support, model integrity, presentation quality, refreshability, and user control make them genuinely banker-ready rather than AI-generated drafts?

Research the Initial Design ICP's expectations for Excel, PowerPoint, Word, PDF, HTML, trackers, source ledgers, and supporting schedules. Determine the hero deliverable, companion artifacts, required edit and refresh behavior, formatting and template expectations, citation and source-to-cell requirements, and the distinction between working draft, review-ready, and external-use postures. Produce a linked Markdown asset; do not build the deliverables in this ticket.

## Answer

V1's Hero Deliverable is the **Controlled Auction Execution Package**: a stage-spanning, revision-controlled Deliverable family inside the Controlled Sell-Side Auction Deal Book, not one file or static PDF. Its required core is an editable Analysis & Valuation Workbook and Auction Control Workbook; stage-triggered PPTX Teaser/CIM and DOCX Bid Evaluation & Recommendation Memo; exact PDF reader/circulation representations; machine-trackable source/evidence and control records; an in-app review/readiness surface; and an immutable export/archive package. Conditional Management Presentation, update deck, process letters, and standalone schedules are included only when the Deal stage or audience requires them.

Every result must preserve Banker-native structure, exact source/model lineage, deterministic recalculation and cross-artifact QC, rendered/PDF parity, protected Banker edits, three-way round trip, immutable Revisions, impact-driven refresh, audience-bound readiness, and a separate exact-version External-Use Decision. A file opening, looking polished, carrying a footnote, or passing deterministic checks does not establish Professional Usability or authorization to circulate.
