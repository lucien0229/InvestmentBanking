# 30 — Produce a complete index-first Archive Package

**What to build:** Let the Banker inspect complete Deal history and create a portable, index-first Archive Package that binds every permitted source, evidence, analysis, process, Deliverable Revision, native/reader artifact, Decision, QC result, external-use event, Job, lifecycle event, schema, manifest, hash, lineage edge, and declared exclusion.

**Blocked by:** 15 — Reimport Banker edits through a protected three-way comparison; 25 — Traverse Exclusive Execution, Signed, Closed and failure branches; 26 — Authorize, deliver and observe one exact external Revision; 28 — Pause, archive and reactivate a Deal without losing authority.

**Status:** ready-for-agent

- [ ] History & Portability presents immutable ordered material history and exact current pointers without flattening correction, Revision, stage, authorization, delivery, actual use, archive, or reactivation into one state.
- [ ] The package index identifies Deal/Package, included object and Revision identities, file roles, exact hashes, schemas, templates, engines/renderers, lineage, QC, Decisions, missing/excluded items, limitations, and export time.
- [ ] Package scope includes only permitted originals and representations and excludes provider secrets, runtime credentials/state, unauthorized third-party content, and broader Recipient/Account authority.
- [ ] Independent observers can resolve each listed file and control record to exact bytes/version and verify canonical manifests/signatures without treating a digest as proof of correctness, authorship, suitability, or authorization.
- [ ] Validation fails when any required file, manifest entry, hash, lineage record, applicable Decision, declared exclusion, or index relationship is missing or inconsistent.
- [ ] Archive Package creation neither extends Recipient Access nor implies external use, deletion, or Account cancellation.
- [ ] The complete package and history path satisfies AC-064 and the export/archive portions of AC-079.
