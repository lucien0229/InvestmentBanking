# Stream Protected Deal Objects through a dedicated gateway

V1 streams authorized Protected Deal Object reads through a dedicated Protected Object Gateway rather than giving the Web, control plane, or general-purpose Workers unrestricted synchronous decryption authority. The control plane authorizes the exact Actor or Recipient Session, object, Revision, purpose, and current posture; the Gateway revalidates the resulting short-lived scope, reads immutable ciphertext, unwraps only the required data key through Google Cloud KMS, and streams plaintext through Caddy without durable plaintext or a reusable public URL. This adds a private runtime and an extra hop to separate business authority from the privileged file data plane and to contain the effect of a compromised application component.
