# Quarantine every upload before substantive processing

Every uploaded file enters Deal-bound Quarantine and is unavailable to AI, Office/PDF engines, OCR, user preview, or accepted Source Material paths until byte integrity, actual type, malware, archive, active-content, and isolated structural checks complete. Scanner errors, stale required signatures, timeouts, engine limit exhaustion, malformed containers, and incomplete coverage fail closed as `scan_incomplete` or another precise blocker rather than clean; only an immutable original that passes the full policy may advance, while any safe preview or normalized representation is a separately identified derived object. This accepts delayed or rejected ingestion to prevent an untrusted parser result or scanner limit from becoming an implicit security decision.
