# Deploy V1 on one United States-region VPS

V1 begins on one VPS located in the United States with no less than 8 vCPU, 16 GB DDR5 RAM, and 512 GB NVMe storage. The host runs the Web application, control plane, and separated workers, while its local PostgreSQL and file persistence are limited to development, synthetic Project Northstar data, and pre-production verification; the first environment permitted to accept Confidential Deal Material uses the separately selected United States-region managed PostgreSQL and object storage. This fixes a single compute-host failure boundary without making the VPS the only production copy of authoritative state or Deal Material, and the Technical Design must preserve restart, restore, and host-replacement procedures rather than implying high availability.
