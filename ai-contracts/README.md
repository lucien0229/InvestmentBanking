# Versioned AI contracts

This directory is the source of the four enabled source-proposal task packages. The control plane compiles an immutable manifest, prompt digest, input/output schema digest, context plan, provider profile, and synthetic evaluation manifest into every AI Run. Source fragments are untrusted data and are never treated as instructions.

The packages are proposal-only. They cannot create Facts, Assumption approvals, Human Decisions, Professional Usability, Readiness, or external actions. Confidential and Restricted material remains disabled until a compatible HelloX capability and processing-evidence profile is verified.
