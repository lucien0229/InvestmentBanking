# Use composite version-bound Native Locators

Every Evidence and controlled native reference binds an exact Source Record representation and byte digest to a versioned selector profile containing the strongest available structural selector plus content quote/context and normalized geometry where applicable. PDF, XLSX, PPTX, DOCX, CSV, JSON, HTML, and EML use format-specific selectors, while human-readable page, slide, sheet, heading, row, or field labels remain secondary display aids; resolution records parser identity and returns moved, ambiguous, or unresolved instead of guessing when uniqueness is lost. This accepts a larger locator schema and explicit failures to prevent mutable page numbers, cell addresses, object order, or text positions from silently rebinding Evidence to the wrong content.
