# Separate Office production engines from compatibility truth

Production workers use server-side document libraries and rendering engines rather than Microsoft Office desktop automation. Declared XLSX, PPTX, DOCX, and Reader Copy compatibility is established separately in an isolated non-production Windows environment against an exact Microsoft 365 Current Channel build that opens, recalculates where applicable, saves, renders, and compares the supported matrix; current Microsoft 365 for Mac provides secondary open, save, and visual smoke evidence but is not formula truth, and no separate Excel 2016, 2019, 2021, PDF/A, PDF/UA, or universal-viewer claim follows without its own evidence. Structural-library, Aspose, LibreOffice, or Mac success alone cannot authorize a Capability Manifest claim. This avoids an unsupported and unstable production Office dependency while retaining version-bound evidence from the primary application whose compatibility the product claims.
