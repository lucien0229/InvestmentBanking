# Commit audit history with signed daily checkpoints

V1 records security-, authority-, source-, judgment-, Revision-, external-use-, commercial-, deletion-, and recovery-relevant actions as privacy-minimized append-only Audit Events chained per Account by cryptographic digest. Each production day ends with an Audit Checkpoint signed by a dedicated environment-specific Ed25519 audit key and copied to both an immutable Supabase object path and the encrypted VPS recovery set; corrections append new events, and no product or operator path updates committed history. This adds ordered hashing, a separate signing purpose, and checkpoint verification so later omission or mutation is detectable without converting authoritative current state to Event Sourcing or claiming external notarization and non-repudiation.
