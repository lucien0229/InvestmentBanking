# Do not implement content support access in V1

V1 has no support-personnel role, Banker impersonation, administrative Deal viewer, or content-level break-glass path. A Deployment Operator may use privacy-safe runtime metadata to deploy, isolate, restart, revoke, rotate, and restore infrastructure, but cannot enter a Banker or Recipient session, decrypt Deal Material through the product, change domain state, or copy content into operational tooling; if diagnosis would require content access, the user receives a bounded self-service recovery or export path instead. This accepts slower diagnosis of content-specific defects to prevent a nominal support capability from becoming a second, weakly governed Deal-access system before the product has the staffing and controls to operate it honestly.
