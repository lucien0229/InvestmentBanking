# Reject executable content and scope external dependencies

V1 rejects substantive processing of macro-enabled or binary Office formats, VBA projects, executable embedded packages, unsafe OLE content, encrypted files, and containers whose active content cannot be safely enumerated. Non-executed external workbook links, Power Query, data connections, linked sources, and non-executable embedded documents may be preserved as metadata, but the product never refreshes them and blocks only the dependent Calculations, Models, Analyses, or Deliverables until the referenced source is uploaded and mapped or an authorized dependency-free version is supplied. This accepts narrower format coverage while avoiding both execution of customer-controlled code and the unnecessary rejection of independently verifiable content in an otherwise usable file.
