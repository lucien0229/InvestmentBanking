# Require provider evidence before confidential AI egress

The fixed HelloX AI Provider Route may process only synthetic or otherwise non-confidential test material until a versioned AI Provider Capability Profile has separately verified the exact API and model contract and established acceptable evidence for processing location, retention, training use, provider access, security posture, limits, and error behavior. After that gate is satisfied, each AI Run still requires Paid Preflight, Rights Posture, data-class compatibility, minimal task-specific selection, and Account and Deal isolation; Restricted Deal Material requires an explicitly compatible profile rather than inheriting approval for ordinary Confidential Deal Material. A reachable endpoint, valid credential, OpenAI-compatible interface, or model-name match never grants confidential-processing eligibility, and a missing compatible profile blocks the capability instead of triggering an unverified model, provider, or route fallback.
