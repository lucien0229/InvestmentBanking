# Isolate untrusted processing behind a host-owned sandbox supervisor

V1 executes untrusted file inspection, parsing, Office/PDF processing, rendering, and public-Web capture in disposable rootless Podman containers launched by a host-owned Sandbox Supervisor running as a dedicated operating-system user. Application containers call only a narrow profile-based Unix-socket contract and never receive the Docker or Podman API socket; the Supervisor permits only pinned image digests, fixed commands, exact Job-scoped mounts, bounded resources, read-only roots, temporary output, and either no network or the separately constrained public-fetch egress profile. A dedicated Public Fetch Coordinator owns public-Web Jobs without Deal-decryption or provider credentials. This accepts an additional host service and container runtime to prevent a malicious file, parser, renderer, or public page from turning a Worker compromise into persistent application or host authority.
