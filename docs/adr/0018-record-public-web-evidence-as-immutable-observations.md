# Record public web Evidence as immutable observations

V1 may retrieve only public, unauthenticated HTTPS resources through a bounded SSRF-resistant capture path and creates a new Web Evidence Observation for every retrieval rather than mutating an earlier Source Record. Where Rights Posture permits, the observation retains the exact response bytes, allowed headers, canonical URL, retrieval time, response metadata, SHA-256 digest, isolated render, extracted representation, parser identity, Processing Coverage, and Native Locators; where full retention is prohibited, it retains only permitted citation context and an explicit live-only or snapshot-prohibited limitation, requires revalidation before material prospective reliance or circulation, and treats disappearance or material change as stale or blocked rather than silently copying or overwriting content. The product does not authenticate, submit forms, bypass access controls, or execute page-originated actions, and every later retrieval triggers a new Source Record and Impact Assessment.
